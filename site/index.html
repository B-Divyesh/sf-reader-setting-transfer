A small tool for a real annoyance

Tune once. Read without the setup ritual.

Reader modes usually start from their defaults. This one starts from yours—and tells you exactly what it changed.

  1. 01

    Make your reading card

    Choose text scale, line length, spacing, letter shapes, contrast, and reduced motion. See every change in a live preview.

  2. 02

    Open any article

    Select the extension on a public article. It keeps headings, lists, quotes, tables, and links—without the surrounding clutter.

  3. 03

    Stay in control

    See which profile is active, make quick adjustments, or turn the reader off for that site and return instantly.

Open, inspectable, portable

Your preferences aren’t a black box.

The profile is a tiny JSON file you can export, read, and share. It contains settings—not browsing history—and needs no cloud account.

  • Visible values, not vague presets
  • Import on another browser
  • Per-site off switch for imperfect extraction

Privacy by construction

Reading history stays out of our hands.

Stored locallyYour profile, site overrides, and current article stay in browser extension storage.

Sent nowhereNo account, analytics SDK, remote fonts, or article-processing server.

Easy to clearRemove the extension and its local data leaves with it.

Install the v1 package

Four steps, then one click per article.

  1. Download and unzip the extension package.
  2. Open chrome://extensions in Chrome or Chromium.
  3. Turn on Developer mode, choose “Load unpacked”, and select the unzipped folder.
  4. Pin Reader Setting Transfer and open it on a public article.
